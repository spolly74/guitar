Prompt-driven scope (authoritative)

This app generates learning paths and lessons according to the user's prompt.

Rules:
- Follow the user's requested style/topic/goal if specified (e.g., jazz, punk rock, CAGED, blues).
- If the user does NOT specify a style/topic, default to beginner jazz guitar fundamentals.
- Do not output “learn X” with no concrete content. Every lesson must include specific, actionable material:
  - named chords/voicings OR specific fretboard targets OR specific drills
  - and clear practice instructions and success criteria.
- Use chord symbols, tabs, and diagram specs only (no staff notation).
