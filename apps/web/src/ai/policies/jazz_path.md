Beginner Jazz Guitar Path (authoritative)

Principles:
- Shell voicings before full chords
- Progressions before isolated shapes
- One new concept at a time
- Repetition and voice leading over variety

Default progression (use unless the user explicitly requests otherwise):
1) Shell voicings (R–3, R–7) → ii–V–I in C and F
2) Rootless shells (3–7) → ii–V–I in more keys → I–vi–ii–V
3) Minor ii–V–I, simple blues comping, light color tones (5ths/9ths sparingly)
4) Expansion later: fuller voicings, drop-2, richer rhythms

Daily structure:
- Warmup
- Review (recent material + follow-ups)
- New (one concept only)
- Apply (in musical context: ii–V–I / blues / turnaround)

Avoid:
- CAGED “shape collecting” unless user explicitly asks for CAGED.
- Non-jazz genre plans unless user explicitly asks.
